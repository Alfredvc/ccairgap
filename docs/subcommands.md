# Subcommands

| Subcommand | Description |
|------------|-------------|
| `list` | List orphaned sessions on disk. |
| `recover [<id>]` | Run handoff (fetch sandbox branch, copy transcripts, rm session dir if clean). Idempotent. Preserves session on dirty tree, orphan-branch commits, or scan failure — commit or discard the work, then re-run. Aborts if the container is still running; stop it first. With no `<id>`, falls back to `list`. |
| `discard <id>` | Delete a session dir without running handoff. |
| `attach <id>` | **Advanced.** Spawn a second interactive selected agent inside the running container `ccairgap-<id>` via `docker exec`. Defaults to the session manifest agent; old manifests without `agent` default to Claude. `--agent claude\|codex` overrides when the matching in-container state exists. `attach` is the only subcommand that accepts a selected-agent `--` tail: Claude uses the Claude denylist and Codex uses the interactive Codex allowlist. Lifecycle: exiting the attached agent does **not** stop the container (only the PID-1 exit does), so handoff fires only when the original session ends. Resume is not supported on attach — use `ccairgap -r <id-or-name>` to start a new session that resumes a transcript instead. |
| `exec -- <command...>` | Prepare the same selected-agent environment as a normal launch, then run an arbitrary command as the container entrypoint payload. The `--` separator is required and every token after it becomes the exact command argv; ccairgap does no shell parsing. `--agent` selects which prepared environment is staged (`claude` or `codex`), not the final binary. `--print` and `--resume` are not supported. Canonical examples: `ccairgap exec -- aharness recipe-driven-design.fsm.ts` and `ccairgap exec --agent codex -- aharness recipe-driven-design.fsm.ts`. |
| `doctor` | Agent-aware preflight checks: Docker running, selected-agent credentials present, image present/stale, state dir writable, `git` + `rsync` + `cp` on PATH. Resolves the same exact agent versions launch would use, including config/CLI `--docker-build-arg` values and `CCAIRGAP_CC_VERSION`, and reports the versioned image tag for those versions; if version resolution fails, the image row fails without aborting the whole command. Defaults to config `agent`, then Claude; `--agent claude\|codex` overrides config. Codex doctor sanitizes `$CODEX_HOME/auth.json` for status and never prints auth secrets. Treats the current generated extension Dockerfile as up to date, and warns when other sidecar Docker assets drift after a CLI upgrade. |
| `init` | Scaffold `.ccairgap/{Dockerfile, config.yaml}`. The Dockerfile uses ccairgap's managed `CCAIRGAP_RUNTIME_BASE_IMAGE` build arg, leaves a slot for project packages, then installs/verifies the resolved host agent versions at the end. Fails if either file exists; `--force` overwrites both. Add `--user` to scaffold the user-wide layer instead (see below). |
| `init --user` | Scaffold the user-wide config dir — `$XDG_CONFIG_HOME/ccairgap/` (default `~/.config/ccairgap/`) — creating `config.yaml` and an empty `integrations/` subdirectory. Fails if `config.yaml` already exists; `--force` overwrites it (the `integrations/` dir is always created if absent). Does not touch the project-layer Dockerfile. See [docs/config.md §"User-wide config"](config.md#user-wide-config) for all accepted keys and precedence. |
| `inspect` | Dump every hook, MCP server, env var, and marketplace mount the container would see at launch. JSON to stdout; `--pretty` for tables. Read-only. `--agent codex` adds sanitized Codex config, auth, session counts, and warnings without printing secrets. |
| `install-completion [<shell>]` | Install shell tab-completion (bash/zsh/fish). Writes one source line into your shell rc via `@pnpm/tabtab`. Completion covers subcommand names including `exec`, launch flags, `codex-args`, and dynamic candidates: session ids for `recover` / `discard` / `attach`, `--agent` after `attach`, custom titles for `-r` / `--resume`, shell names for `install-completion`. Omit `<shell>` to be prompted. |
| `uninstall-completion` | Remove ccairgap completion from every supported shell rc. Idempotent. |
